# homebrew-tap

Homebrew formulas for [a9a4k](https://github.com/a9a4k) tools.

## Usage

```bash
brew install a9a4k/tap/tour
```

Or tap once, then install any tool from this tap by name:

```bash
brew tap a9a4k/tap
brew install tour
```

## Available formulas

- [`tour`](Formula/tour.rb) — Local code review tool with AI annotations: TUI + webapp over a pinned git diff. Source: [a9a4k/tour](https://github.com/a9a4k/tour).

## Upgrading

```bash
brew upgrade tour
```
